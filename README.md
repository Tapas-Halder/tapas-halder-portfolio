## ▶️ Run Locally

No framework or build tool is required.

### 1. Clone the repository

```bash
git clone https://github.com/tapashalder/tapas-halder-portfolio.git
```

### 2. Open the project

```bash
cd tapas-halder-portfolio
```

### 3. Run

Simply open `index.html` in your browser.

For development, you can also use the **Live Server** extension in VS Code.
